# fanwaave-cli

Rust CLI for Fanwaave and push-notification delivery across web, mobile, and desktop. Talks to `fanwaave-api-server.rs`.

## Configuration boundaries

- `.cli-flags.toml` is the public argv contract and is parsed/audited only by the canonical [`flags-2-env`](https://github.com/flags-2-env/flags-2-env) Rust binding.
- `.fanwaave-cfg.toml` is the Fanwaave domain runtime contract. Its independent TypeSpec and JSON Schema Draft 2020-12 authorities live in `fanwaave/fanwaave-interfaces` and are admitted fail-closed with `ORESoftware/typespec-json-schema-validator` (TJSV).
- `fanwaave-lib-core` performs semantic TOML validation and resolution.
- Effective Fanwaave precedence is explicit argv (`provided_flags`) > ambient environment > non-secret `.fanwaave-cfg.toml` default.
- Secret Fanwaave bindings may not have plaintext defaults and may not arrive through the argv override channel.

Env key constants used by the CLI are generated by `f2e generate` from `.cli-flags.toml` into `generated/{rust,dart,typescript,gleam}`. Fanwaave domain defaults are not duplicated into `.cli-flags.toml`.
